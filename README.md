# Calculadora Online Moderna

Uma calculadora científica online, moderna, responsiva e gratuita. Permite realizar operações matemáticas básicas e avançadas, como soma, subtração, multiplicação, divisão, porcentagem, raiz quadrada, logaritmo e funções trigonométricas (sin, cos, tan). Possui temas claro, escuro e coloridos, além de salvar o último cálculo e tema escolhido.

## Funcionalidades

- Operações básicas: +, -, ×, ÷, %, parênteses
- Funções científicas: √, log, sin, cos, tan (em graus)
- Teclado virtual e suporte ao teclado físico
- Temas: Claro, Escuro, Forest (verde), Sunset (laranja/roxo)
- Responsiva: funciona em desktop e celular
- Histórico do último cálculo e tema salvos no navegador
- Código aberto sob licença MIT

## Como rodar o projeto

Você pode rodar a calculadora de duas formas:

### 1. Usando o Live Server (recomendado para desenvolvimento)

1. Instale a extensão [Live Server](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer) no VS Code.
2. Clique com o botão direito no arquivo `index.html` e selecione **"Open with Live Server"**.
3. O navegador abrirá automaticamente a calculadora.

### 2. Abrindo diretamente no navegador

1. Navegue até a pasta do projeto.
2. Dê um duplo clique no arquivo `index.html` ou abra-o manualmente no seu navegador favorito.

> **Obs:** Não é necessário instalar nada, basta ter um navegador moderno (Chrome, Edge, Firefox, etc).

## Estrutura dos arquivos principais

- `index.html` — Página principal da calculadora
- `css/` — Pasta com os arquivos de estilos e temas (`themaclaro.css`, `darkthemasoft.css`, `foresttheme.css`, `sunsettheme.css`, `customStyle.css`)
- `js/` — Scripts de funcionamento (`calculatorScript.js`, `userState.js`)
